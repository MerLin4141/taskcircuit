The isolated fresh-install/Mock and v0.1.2 upgrade smoke tests were repeated after that final regression.

## Hygiene and staging

The local scan found no real secret values; two credential-shaped values in an Event validation test are deliberate fictional strings. No runtime database, sidecar, log, PID, `.env` or smoke home was included in the candidate inventory. [Staging preview](v0.2.0-staging-preview.md) lists intended paths and explicitly excludes the local-only comparison document. Nothing was staged.

## Known limits

Actual Windows reboot/logon and Linux process-group cleanup were not tested. The isolated Windows recovery test used a controlled polling delay. Cancellation did not include a complete independent descendant inventory. Real deadline, response-loss, Worker crash and Hub crash were not independently injected against both real CLIs. Watch is not a complete Root timeline; Automation creation requires trusted configuration. Trusted Local is not an authentication boundary or OS sandbox, and external side effects are not exactly-once.
