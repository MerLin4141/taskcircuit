## Known limitations

- External side effects are not exactly-once. Killing a local Agent cannot retract an external request already sent.
- Trusted Local, Windows Job Objects and process-tree control are not an OS security sandbox; filesystem, network and credential isolation are not provided.
- Detached or escaped descendants may survive cleanup; Linux process-group cleanup remains unvalidated.
- Windows reboot/logon recovery remains unvalidated.
- Real compatibility is evidenced only for the tested CLI versions and scenarios; Later and real response-loss reconciliation were not tested.
- Abnormal Schedule isolation lasts for one tick, not persistent quarantine; repeated diagnostics may occur.
- Receipt metadata grows with executions. Older retry records lacking proof of safety may stop for review rather than automatically retry.
