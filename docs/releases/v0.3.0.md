# TaskCircuit v0.3.0

## English

TaskCircuit v0.3 introduces Plugin Registry API 1 for Agent, Source, and Channel plugins. Built-in implementations use the registry, and explicitly configured external plugins can be loaded as trusted local code. Declarative rules can be validated with `taskcircuit apply --dry-run` and applied atomically. Reapplying identical rules is unchanged; changes create immutable Automation versions, and existing Roots keep their pinned version. Existing v0.2 configurations remain valid, `apply` is optional, and database schema remains 10.

Windows is the primary validated platform. Trusted Local plugins are not sandboxed; loopback is not authentication, and capability metadata is not an OS filesystem sandbox. External effects are not guaranteed exactly once. Generic active Source lifecycle methods are not implemented. An actual Windows reboot/logon cycle was not tested during RC validation. See the [upgrade guide](../upgrade-v0.3.md), [quick start](../quickstart-v0.3.md), [plugin guide](../plugin-authoring.md), and [rules guide](../declarative-automation.md).

## 简体中文

TaskCircuit v0.3 引入 Plugin Registry API 1，支持 Agent、Source 和 Channel 插件。内置实现通过注册表使用；显式配置的外部插件作为本机可信代码加载。声明式规则支持 `taskcircuit apply --dry-run` 预演和原子应用；相同规则重复应用不会产生新版本，修改规则会创建不可变的 Automation 版本，已有 Root 保持原版本。现有 v0.2 配置仍然有效，`apply` 是可选功能，数据库 schema 保持 10。

Windows 是主要验证平台。Trusted Local 插件不受沙箱隔离；回环地址不是身份认证，能力元数据也不是操作系统文件沙箱。外部操作不保证恰好执行一次。通用主动 Source 生命周期尚未实现。本次 RC 验证没有进行实际 Windows 重启或重新登录。详见[升级指南](../upgrade-v0.3.md)、[快速开始](../quickstart-v0.3.md)、[插件说明](../plugin-authoring.md)和[规则说明](../declarative-automation.md)。
