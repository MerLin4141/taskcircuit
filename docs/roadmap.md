# Roadmap

## v0.2 — Durable Autonomous Loop

Released. Local durable automation, bounded continuation, human input and scheduling, with Codex, Claude Code and Mock Agent. See the [v0.2 release notes](releases/v0.2.0.md) for verified scope and limitations.

## v0.3 — Plugin Architecture

Released. Source, Agent and Channel plugin boundaries, trusted external plugin loading and declarative automation rules. See the [v0.3 release notes](releases/v0.3.0.md).

## v0.4 — Automation Ecosystem

Planned development focuses on real Sources, Channels and reusable automation integrations built on the v0.3 plugin and runtime foundation. See the [Phase 0 design](design/v0.4-automation-ecosystem.md) for the proposed scope.

Longer-term possibilities include isolation, remote workers, multi-user authorization and cloud runtime.
