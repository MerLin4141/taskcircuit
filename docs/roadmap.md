# Roadmap

## v0.2 — Durable Autonomous Loop

Release candidate: local durable automation, bounded continuation, human input and scheduling, with Codex, Claude Code and Mock Agent. See the [v0.2 release notes](releases/v0.2.0.md) for verified scope and limitations.

## v0.3 — Plugin Architecture (tentative)

Stable Source, Agent and Channel extension boundaries, built-in plugins using the same registry, and a simpler declarative automation configuration. Scope and timing are not commitments.

## v0.4 — Automation Ecosystem (tentative)

Explore additional sources, channels and integrations. No release dates are promised.

Longer-term possibilities include isolation, remote workers, multi-user authorization and cloud runtime. These are not v0.2 capabilities.
