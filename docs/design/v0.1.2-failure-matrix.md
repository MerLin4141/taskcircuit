## 关键区分

- fencing 的覆盖范围是 Hub 数据库写入，不覆盖普通外部 API。
- `409` 说明提交未被当前令牌接受，不代表外部 Agent 没有完成工作。
- Windows Job Object 是进程生命周期机制；测试实际杀死临时子进程，不证明文件、凭据或网络隔离。
- 幂等结果回执与重复执行是不同问题：改成可确认重复回执不能单独阻止 Agent 已经重复调用外部系统。
- 计划任务重新触发的幂等只覆盖 `schedule_id + scheduled_for`，不是通用事件来源去重。
