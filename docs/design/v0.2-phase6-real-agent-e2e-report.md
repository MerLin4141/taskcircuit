## UX candidate

Automation create/list/show and Root list/show were added with JSON output and bounded default limits. Automation creation accepts only Agent profiles, event types and workspace paths already present in the Hub's trusted local configuration. This retains the independent trusted workspace check, but means a new user must prepare that configuration before using the create command; it is a documented limitation of the current four-step preview. Doctor adds schema, profile names and home writability checks; missing Agent CLIs remain optional warnings.

The Mock demo creates a Root and runs Continue, Continue, Complete with one Session. It was exercised through the CLI with an independent Hub and background Worker. [Quick start](../quickstart-v0.2.md) and [API notes](../api.md) describe the current preview. Watch renders supported change events in plain language while retaining event types. The existing stream does not supply every Event/Root semantic event, so it does not guarantee the full requested Event received / Root created / Continue narrative. Status retains its existing JSON behavior.
