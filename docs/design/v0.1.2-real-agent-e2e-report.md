## Reliability

- P0 semantics: 两个真实取消案例观察到 `execution_outcome_unknown`，没有自动重做。测试通过临时 Hub 的取消接口触发，并观察本次直接启动的进程退出；未单独观察每个后代进程。
- Result Receipt: 两个真实完成案例均保存回执，使用回执的 submission ID 和 digest 查询得到 committed；Ask/Resume 各保存两个回执。
- Reconciliation: **NOT TESTED** for real Agents；没有在真实 Agent 的结果提交时丢弃 HTTP 响应。此前 P1 假进程测试覆盖该故障窗口。
- Heartbeat: 实际 Worker 正常运行到结果提交；未在真实 Agent 执行期间注入网络中断或明确失权，恢复语义仍以 P0/P1 假进程测试为证据。
- Stale lease: 完成后的无效凭据提交均返回 409；这不是对真实旧租约 token 与并发新所有者的单独实测，该场景仍以 P0/P1 受控测试为证据。
- Scheduler: 本轮真实任务未使用 Later 或注入时钟回拨；完整本地回归包含既有 Scheduler 测试。

## Security Boundary

TaskCircuit v0.1.2 使用 **Trusted Local** 执行模型，不提供 OS 级安全沙箱保证。外部副作用没有 exactly-once 保证；终止本地 Agent 不能撤销已发送的外部请求。进程生命周期控制不能代替安全隔离，脱离受控进程树的后代可能逃逸。
