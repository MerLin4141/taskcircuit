# TaskCircuit 产品定位与设计边界

> 状态：设计提案，未获批准、未实现。基线为 TaskCircuit v0.1.1，提交 `4fb7cf13fd7c243c8d2bd82ece34f75ae37a55df`。本文件不改变现有产品承诺。

## 定位

TaskCircuit 是以 Work Item 为中心的本地持久化 Agent 运行时。它接收经过来源校验的事件，根据可信规则决定是否创建或唤醒工作项，持久记录执行和会话；在等待、失败、需要人参与或进程重启时，按明确策略恢复。目标是把“一次 CLI 调用”组织成可追踪、可暂停、可继续且有边界的工作循环。

它不是模型推理框架、提示词编排产品、通用工作流画布，也不是凭借标签就能安全执行不可信代码的沙箱。Agent 决定具体执行步骤；运行时决定谁可触发、关联到哪个工作项、可用能力、执行预算、何时停下以及可追溯的状态变更。

## 对谁有用

- 独立开发者：让需要数小时或跨天的 CLI Agent 工作在退出和重启后有据可续。
- 小团队维护者：把外部事件与某个具体工作项关联，重复投递不会无意产生重复工作，并能在高风险操作前暂停审批。
- 集成开发者：通过清晰的来源、Agent、通道和交付接口扩展能力，而无需改动调度内核。

## 什么叫自主闭环

1. **感知**：来源适配器接收事件，验明来源并保留原始投递标识；事件正文始终是资料。
2. **判断**：用可信规则、当前工作项状态、策略版本和预算，决定忽略、合并、创建、排队、等待人或停止。
3. **行动**：Worker 领取持久化执行意图，调用被允许的 Agent；外部副作用通过受控能力发出。
4. **观察**：记录执行结果、会话、变更和必要的外部回执；无法确定结果时标记为未知。
5. **反馈与继续**：经许可且在共享预算内生成后续事件，或等待人、稍后执行、重试；否则进入可解释的终止状态。

“闭环”不是无条件自我触发。每个根任务都应有跨后续事件共享的深度、次数、时间及资源预算；达到上限停止并说明原因。当前版本尚无这些统一预算。

## 基本对象

Work Item 表达一个持续的目标；Execution 是一次有独立状态和租约的执行尝试；Agent Session 是可恢复的外部会话；Interaction 是提问、回答或审批；Event 是经验证来源提交的不可变输入；Decision 记录一次规则判断。多个事件可以关联同一 Work Item，一个 Work Item 可以有多个 Execution；会话复用不意味着重复执行外部动作安全。

## 明确不承诺

- 不把“收到事件”或“Agent 返回成功”当作外部结果已核实；外部动作可能成功但回执丢失。
- 不保证外部系统的恰好一次执行，也不让重复事件自动扩大权限。
- 不以“本地”“不在提示中”或插件能力声明替代 OS 强制隔离；v0.1.1 不为恶意同用户进程提供文件隔离。
- 不声称本次完成了实际 Windows reboot/logon、真实 Agent E2E、隔离或生产验证。
- 不以新文档覆盖已发布的既有路线图。版本和顺序仅供评审；批准后另行同步正式文档。

## 成功标准

用户能回答：这个事件为何进入这个工作项、使用了哪个策略、当前在哪一步、为什么暂停或停止、重试会不会重复外部动作，以及由谁批准了什么。需要通过持久化、竞争、崩溃和端到端测试逐项证明；架构图和接口草案本身不是验证结果。

产品定义：面向 CLI Agent 的持久化自主执行与自动化编排引擎；Runtime 是底座，事件接入、规则、反馈循环和插件共同构成完整目标产品。

**One task. Multiple executions. One autonomous loop.**

核心链路：Event → Decide → Execute → Observe → Continue → Complete。

## 第二轮：从长期定义到有界执行

以下是尚未实现的目标领域模型：Automation Definition 是可持续启停和版本化的长期自动化定义；Automation Root 是某次触发产生的有界循环，拥有独立生命周期和共享预算；Work Item 是该 Root 内持续处理的具体工作对象。一个 Root 可含多个工作项，每个工作项只属于一个 Root；一个外部 Event 可经可信策略关联多个 Root，反馈子事件继承原 Root。Execution 是一次尝试，工作项可跨执行复用 Agent Session。

例如，每天检查三个仓库的 Definition，在每天触发时产生一个有界 Root；该 Root 下三个工作项共享预算、分别保留执行历史。工作项之间默认故障隔离；Root 终止后，新事件产生新 Root，而不是无限重启旧预算。跨 Root 的相同业务对象可以保存只读前驱关系，但不共享可变状态。无周期的一次性任务可由系统使用内置单次 Definition，不要求用户额外配置。

Agent 提供执行结果和建议，可信控制面决定是否继续、审批、派发或停止；它不能凭输出增加自己的权限。预算、来源认证和隔离均是目标能力，不代表 v0.1.1 已经实现，现有 Trusted Local 也不是安全沙箱。
